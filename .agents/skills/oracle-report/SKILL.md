# Oracle Enterprise Reporting & BI Publisher (/oracle-report)

When `/oracle-report` is invoked:
1. For Formal Root Cause Analysis (RCA):
   - Generate full post-mortem report using [templates/rca_incident_report.md](file:///d:/Techwaves-egy/Oracle%20Skill/templates/rca_incident_report.md) with **Techwaves EGY** logo, timeline, 5-Whys, and CAPA action items.
2. For BI Publisher / XML Publisher Reports:
   - Generate high-performance XML Data Template: [templates/bi_publisher_data_template.xml](file:///d:/Techwaves-egy/Oracle%20Skill/templates/bi_publisher_data_template.xml).
   - Generate automated concurrent program registration: [templates/fnd_concurrent_registration.sql](file:///d:/Techwaves-egy/Oracle%20Skill/templates/fnd_concurrent_registration.sql).
   - Generate bursting control file for automated email distribution.
3. For Capacity Planning:
   - Generate tablespace and resource growth forecasts using [templates/capacity_planning_report.md](file:///d:/Techwaves-egy/Oracle%20Skill/templates/capacity_planning_report.md).
